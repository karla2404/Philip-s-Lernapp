WIRTSCHAFTSRECHT – LERNTRAINER

1. ZIP entpacken.
2. index.html und questions.js zusammen in ein öffentliches GitHub-Repository hochladen.
3. Unter Settings > Pages: Deploy from a branch, main, /(root) auswählen.
4. Nach Veröffentlichung den GitHub-Pages-Link an den Schüler schicken.

Lokal kann index.html auch direkt im Browser geöffnet werden. Der Lernfortschritt wird nur im jeweiligen Browser gespeichert. Keine Anmeldung, kein Server.

Enthält 35 sorgfältig formulierte Multiple-Choice-Fragen zu sechs Themen. Bei Mehrfachantworten müssen alle korrekten Optionen gewählt werden. Rechtliche Vereinfachungen und individuelle Sachverhalte sind gesondert zu prüfen.
